Häufige Fragen

Spielt HASA automatisch für mich?

Nein. HASA unterstützt dich mit Übersichten und Hinweisen. Es führt keine Spielaktionen für dich aus.

Kann ich private Daten anderer Spieler sehen?

Die Galaxiedatenbank berücksichtigt die eingestellten Freigaben. Private Daten anderer Spieler werden nicht automatisch offengelegt.

Welche Version wird hier angeboten?

Die öffentliche stabile Fassung HASA 1.2. Künftige offizielle Updates werden über Tampermonkey bereitgestellt.
